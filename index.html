MERG-DEV APT Repository

An APT repository of the Model Electonic Railway Group, which is used for hosting Raspbian packages.

The repository contains Raspbian Trixie (Debian 13) packages for ARM (32-bit) and ARM64 (64-bit).

To add the repository to your installation, click on the mergdev-rpi13.sh script to download it. After the download has completed, open a terminal and execute the script using the following command :

sudo sh mergdev-rpi13.sh↲

This will add the repository to your sources list and install the necessary GPG key.

Alternativey open a terminal and run the following commands:

  1. You may need to install the following packages:

    sudo apt-get update↲
    sudo apt-get install ca-certificates gpg wget↲

  2. Obtain a copy of our signing key:

    wget -O - https://emthornber.github.io/rpi13repo/raspbian/gpg-pubkey2.asc 2>/dev/null |↲
    gpg --dearmor - |↲
    sudo tee /usr/share/keyrings/mergdev-archive-keyring2.gpg >/dev/null↲

  3. Add the repository to your sources list and update.

    echo 'deb [signed-by=/usr/share/keyrings/mergdev-archive-keyring2.gpg] https://emthornber.github.io/rpi13repo/raspbian/ trixie main' |↲
    sudo tee /etc/apt/sources.list.d/mergdev.list >/dev/null↲
    sudo apt-get update↲

Now you can install any package from our APT repository. As an example, try installing the autowap package either from the command line:

sudo apt-get install autowap↲

or using the Software application in Raspbian vis

Raspberry | Preferences | Add / Remove Software

and searching for autowap
